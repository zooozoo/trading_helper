이 저장소에서 Claude Code를 메인, Codex를 리뷰 담당으로 사용하는 국내 이벤트 전략 검증 프로젝트를 진행해줘.

먼저 CLAUDE.md, AGENTS.md, README와 docs를 읽고 현재 테스트를 실행해.
초기 전략은 docs/STRATEGY_V0.md이며 아직 검증되지 않은 가설이야.

첫 작업은 데이터 확보와 입력 검증이야:
1. 가격/공시/기업행동/거래일/상장폐지 데이터 공급자 후보를 공식 문서로 조사해.
2. 무료 데이터로 복원 가능한 범위와 불가능한 범위, 비용·약관을 정리해.
3. OpenDART 키는 환경변수에서 읽고 출력하지 않도록 원본 수집기를 구현해.
4. 신규 수주·정정·해지를 구분하고 정규화하되 불확실한 추출은 수동 확인 대기 상태로 둬.
5. DATA_CONTRACT 형식의 검증기를 만들고 원문과 숫자/시점/단위가 맞는지 점검해.
6. 실제 표본을 확보할 수 없으면 명확히 보고하고 demo 성과를 실제 성과로 대체하지 마.

원본을 보존하고 조회 당시 이용 가능 자료만 사용해. 과거 재무 위험 승인도 근거 원문이 필요해.
작업 후 변경 파일, 테스트 결과, 데이터 확보 결과, 남은 한계, Codex 검토 항목을 보고해.
이번 단계에서 자동 주문이나 예약 실행은 추가하지 마.
