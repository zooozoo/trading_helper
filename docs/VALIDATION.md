# 검증 계획

## 구현 상태

실행 가능: 전략 설정, 일봉 신호 검사, 수량/손절/익절 계산, 일봉 청산 판정(v0 모델),
CSV 입력 검증기, OpenDART 원본 수집기(공시 목록·원문·manifest), 단일판매ㆍ공급계약
정규화(자동 추출 + 수동 확인 대기열), 단위 테스트.
미구현: 가격·거래일·상장폐지 데이터 수집, 재무 위험 검토 자동화, 주간 모드(v1) 백테스트 엔진,
성과 통계, 기업행동/거래정지/호가단위, 일요일 산출물·ChatGPT 프롬프트 생성기, 증권사 주문.
실데이터 확보 상태: OpenDART 공시 2016~2026, 일별 시세 2020-01-02~2026-10-01(상장폐지 포함) 수집·정규화 완료(`docs/runs/`).
미확보: 공식 휴장일 교차 확인, 기업행동 보정, 관리종목·거래정지 지정 이력.
공급자 조사는 `docs/DATA_SOURCES.md`.
수익성 검증: 수행하지 않음. demo와 테스트는 가상 가격입니다.

## 과거 검증

**구간 분할(제안, 2026-10-06)**: `config/segments_v1.json`. development 2020-01-02~2024-01-31,
validation 2024-02-01~2025-05-31, final 2025-06-01~2026-10-01. 구간 소속은 진입일 M 기준.
첫 실험 결과는 `docs/runs/2026-10-06_W1_development.md`: 개발 구간에서 가설 미지지. 검증 구간 미사용.

**검증 데이터 범위 결정 (2026-10-05)**: 시세 출처(공공데이터포털)가 2020-01-02부터 제공되므로
검증 구간은 **2020-01-02 이후**로 한정합니다. 2016~2019년 공시(약 6,400건)는 가격이 없어 사용하지
않으며, KRX 수동 다운로드로 보완하기 전까지 미사용으로 둡니다. 2020년 이후 범위에서는 일별
스냅샷 덕분에 상장폐지 종목이 포함되어 생존 편향이 해소됩니다. 구간 분할(개발/검증/최종)은
표본과 시장 국면을 본 뒤 확정하고 여기에 기록합니다.

데이터 범위와 품질을 먼저 확인하고 구간을 고정합니다. 기간 배정의 예시는 개발 60%,
검증 20%, 최종 평가 20%이나, 이벤트 표본과 시장 국면을 보고 시작 전에 확정합니다.
시간순 분할, 구간 경계를 넘는 보유 표본은 분리하거나 충분한 간격을 둡니다.
최종 구간을 보고 조정했다면 그 구간은 더 이상 미사용 평가 구간이 아닙니다.

각 실행 기록: Git commit, Python/의존성 버전, 전략 설정, 데이터 해시, 구간, 비용표,
실험 번호, 변경 이유. 실패 결과도 기록. 비용은 거래 시점·시장·상품별 공식 자료로 확인.

기준 전략:
- 동일한 종목군·보유 기간의 이벤트만 이용한 전략(돌파 필터 없음)
- 돌파만 이용한 전략(수주 조건 없음)
- 동일 기간 시장 총수익 지수/배당 재투자 기준

포트폴리오 기준으로 비용 후 수익, 낙폭, 변동성, 거래 수, 승률, 평균 손익,
profit factor, 노출, 현금, 회전율, 미청산 포지션을 보고합니다.
시간과 종목 상관을 고려한 구간별/블록 단위 불확실성 평가를 사용합니다.
거래 수가 적으면 예상 승률·성공 확률을 단정하지 않습니다.

민감도: 비용 증가, 진입 지연, 갭 하락, 보유 기간/임계값 소폭 변경, 상위 수익 거래 제거.
과다한 파라미터 검색을 피하고 시도 횟수를 기록합니다.

## 실제 운영 전 조건

- 시점 편향, 정정 자료, 상장폐지, 자금 초과, 체결 계산 결함 해결.
- 대표 원본 공시의 수동 검토 및 데이터 누락·거래정지 처리 확인.
- 미사용 구간에서 비용 후 성과와 사용자가 정한 허용 낙폭 충족.
- 실제 추천이 가능했던 시점으로 모의투자. 일별/주간 실행 모드를 명확히 구분.
- 8~12주는 초기 관찰 기간의 예일 뿐이며 충분한 표본이나 검증 통과를 보장하지 않음.

## 코드 계산의 한계

청산 함수는 일봉이 정상적으로 거래되었다고 가정합니다. 거래정지/상·하한가 잠김이면
OHLC가 손절 가격을 지나도 주문이 체결되지 않을 수 있습니다. 운영 엔진에서는 별도 처리.
ATR는 단순 평균이며 거래소 호가 단위로 반올림하지 않습니다. 생산 주문 가격으로 쓰지 않음.
수량 함수는 계획 손절 손실만 제한하며 갭과 상관된 동시 손실을 제한하지 않습니다.
