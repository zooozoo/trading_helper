# 인수인계 문서 (2026-10-10 기준)

이 문서는 어떤 LLM·도구가 이어받아도 같은 원칙으로 작업할 수 있도록 프로젝트의 목표, 제약, 데이터, 결정, 결과, 다음 할 일을
한곳에 모은 것입니다. 이전 작업자(Claude Code)의 계정 메모리에만 있던 내용을 전부 옮겼습니다. 저장소 밖의 기억은 없습니다.

## 1. 목표와 현재 위치

- 목표: 국내 주식에서 **주 1회 또는 월 1회 점검과 개장 전 예약 주문만으로 실행 가능한 전략**을 찾아 검증한다.
  수익성이 확인되기 전까지 모든 수치는 가설이다. 자동 주문은 없다.
- 현재 위치: **전략 연구 도구 완성 단계.** 데이터 파이프라인·백테스트 엔진·진단 도구·기록 체계가 갖춰졌고,
  첫 전략군(수주 공시 돌파 단기매매)은 데이터로 기각됐으며, 두 번째 전략군(월간 팩터 포트폴리오)이 개발 구간에서
  "방향이 맞아 보이지만 증거는 약한" 상태다. **검증 구간과 최종 구간은 한 번도 사용하지 않았다.**
- 운영 산출물(월말 종목 바구니 생성기, ChatGPT 보고 프롬프트 생성기, 체결 대조 명령)은 아직 없다.
  전략이 검증 구간을 통과한 뒤에 만든다.

## 2. 사용자 제약 (설계의 전제)

- Claude Code는 회사 계정이었고 2026-10-11 이후 사용 불가. ChatGPT는 개인 계정. 일일 가격 보고는 ChatGPT 예약작업용.
- 사용자의 Mac은 상시 가동되지 않는다. 로컬 스케줄러에 의존하는 설계는 하지 않는다.
- 유료 데이터 없음. 공공데이터포털 데이터는 **비상업(KOGL 4유형)** 조건이라 개인 연구 용도로만 쓴다.
- 매수·매도·보유 판단과 주문은 **사용자가 직접** 한다. LLM은 가격 보고와 설명만 하고, 숫자는 결정적 코드가 계산한다.
- 장중 감시 불가. 모든 주문은 개장 전 예약(지정가·시장가). 청산은 시가 기준으로 모델링한다.

## 3. 환경과 키

- Python 3.12, 외부 의존성 없음(표준 라이브러리). 테스트: `python -m unittest discover -s tests -v` (69개, 전부 통과해야 함).
- API 키는 `~/.zshrc`에만 있다: `OPENDART_API_KEY`(OpenDART, 40자), `DATA_GO_KR_API_KEY`(공공데이터포털, 64자).
  **어떤 로그·파일·채팅에도 키를 출력하지 않는다.** 코드는 환경변수에서만 읽고 manifest·오류 메시지에서 마스킹한다.
- 도구의 셸이 `.zshrc`를 읽지 않으면 `zsh -ic '명령'`으로 실행한다(Claude Code의 Bash가 그랬다).
- 한도: OpenDART 개인 키 20,000건/일, 공공데이터포털 개발계정 10,000건/일. 모든 수집기는 `--max-requests`로 제한하고
  이미 받은 파일은 건너뛰므로 같은 명령을 다시 실행하면 이어받는다. 백그라운드 수집은 세션이 끝나면 죽는다.
- Git: 원격 `github.com:zooozoo/trading_helper` (SSH). 커밋 신원은 저장소 로컬 설정(zooozoo / noreply). `gh` CLI 미로그인.
- 데이터는 **이 Mac의 `data/raw/`, `data/normalized/`, `data/cache/`, `outputs/`에만 있고 Git에는 없다**(총 약 2GB).
  같은 Mac에서 이어가면 재수집 불필요. 다른 컴퓨터면 §5의 명령으로 재수집(한도 때문에 이틀 정도).

## 5. 데이터 (수집 완료 상태와 갱신 명령)

| 데이터 | 범위 | 상태 | 갱신 명령 |
|---|---|---|---|
| OpenDART 수시공시 목록(I001) | 2016-01~2026-10 | 523,455행 | `dart-collect --start 2016-01-01 --end <오늘> --documents` |
| 수주 공시 원문 | 신규 체결 18,711건 전부 | 정규화: 자동 16,749 / 수동 1,962 | 위와 동일 |

| 일별 시세(전 종목) | 2020-01-02~2026-10-01 | 428만 행, 1,656거래일, 3,310종목(보통주 2,902) | `prices-collect --start 2020-01-02 --end <오늘>` |
| 지수 6개 | 2020-01-02~2026-10-01 | 가격지수(배당 제외) | `index-collect --end <오늘>` |
| 재무 주요계정 | 2019~2026 분기 | 124만 행, 2,742종목 | `fundamentals-collect --start-year 2019 --end-year <올해>` |

수집 뒤 정규화: `dart-normalize`, `prices-normalize`, `fundamentals-normalize` (index-collect는 자동). 모든 명령은
`python -m trading_helper <명령>`. 검증: `validate --prices ... --events ... --trades ...`.

데이터의 알려진 성질(상세는 DATA_SOURCES.md):
- 시세는 **원주가(미수정)**. 액면분할·무상증자는 `share_count_changes.csv`의 후보(1.5배 이상/0.67배 이하)로 보정. 소규모 변화 미보정.
- 상장폐지 종목이 일별 스냅샷에 포함되어 생존 편향 없음. 거래정지·무거래는 시가·고가·저가·거래량 0 행 → `halts.csv`.
- 휴장일은 0행. 평일 0행 106일 중 2026-07-17, 2026-10-02는 공식 휴장 여부 미확인.
- 2016~2019년 공시는 시세가 없어 **미사용**. 검증 범위는 2020-01-02 이후로 확정.
- 재무: 분기 손익은 **3개월치**(누적 아님). 4분기 = 연간 − (1~3분기). API가 정정 후 수치를 줄 수 있음(`rcept_no` 기록).
- 공시 접수 시각 미확보(날짜만). 장중·장후 공시 구분 불가.

## 7. 실험 결과 요약 (전부 개발 구간, 재무 위험 필터 미적용, 비용 가정값)

**기각**
- `W1-A/B` 수주 공시 돌파 주간 전략: A(반응일=금요일) 21건으로 표본 부족, B 84건 PF 0.89. 기준(이벤트만) 전략의 양호한 수치는 2020년 반등장 때문.
- `DIAG-02` 이벤트 스터디(4,403건): 공시 효과 약 +1%는 접수일 당일 반영, 사후 1~20일 드리프트 없음(플라시보와 동일).
  반응일 돌파 그룹의 +2.9%/4일은 2020년(+7.3%)이 만든 것, 2022~2024년 음수, 상위 10%가 이익의 55%.
- `SCREEN-01` 수시공시 13개 유형: 전부 드리프트 없음. 특허·임상·라이선스·수주 "투자판단 주요경영사항"은 20일 −1~−7% 되돌림 → **매수 금지 신호**.
- `F1-01` 모멘텀 상위 20: −68%(테마주 거래정지로 매도 불가 46회). 복합(VQL) +5%로 구성 요인보다 나쁨.

**살아남음(미검증)**
- `F1-01` 저변동성 상위 20: 비용 후 +26.2%, 변동성 11.4%, 최대낙폭 −22%, 2022년 −1.7%(코스피 −25%). 가치 상위 20: +24.9%, 낙폭 −42%.
  코스피 가격지수 +12.9%, 코스닥 −3.5%(2020-08~2024-02). 무작위 20종목 대비 백분위 0.78(약함). 비용 부담 연 2%p(회전율 월 60~70%).
  장부가/시총 5분위 단조 증가(월 +1.95%p).
- `SCREEN-02` 자기주식 취득(직접 358건, 신탁 572건): 공시 후 4일 플라시보 대비 +1~2%p, 4개년 모두 양수, 중앙값 0 근처. 얇음.
- 무상증자: 권리락 보정 전이라 판단 보류.

## 8. 다음 할 일 (우선순위, 사전 등록)

**F2-01: 회전율 낮춘 팩터 v2** (개발 구간)
- `strategy_factor_v2.json`을 새로 만들어 v1에서 한 가지만 바꾼다: 보유 종목은 종합 순위 **30위 안에 있으면 유지**, 20위 안의 신규 종목만으로 빈자리를 채운다(완충 규칙). 나머지(유니버스, 요인, 동일가중, 월초 교체)는 동일.
- 기대: 회전율 월 60~70% → 30% 안팎, 비용 연 2%p → 1%p. 수익·낙폭 변화를 F1-01과 같은 표로 기록.
- 조합은 저변동성 단독과 가치 단독만 본다. 다른 조합 탐색 금지.

**검증 구간 평가(한 번만)**
- 대상: F1 또는 F2 중 개발 구간에서 더 나은 저변동성 포트폴리오 하나. 설정 변경 없이 `--segment validation`.
- 통과 기준(실행 전 확정): 비용 후 수익이 코스피 가격지수 +2%p 이상, 최대낙폭 −30% 이내, 무작위 대비 백분위 0.70 이상.
- 통과하면 운영 산출물(월말 바구니·주문 목록 생성기, ChatGPT 보고 프롬프트, 체결 대조 명령) 제작 → 모의투자 2~3개월 → 소액.
  실패하면 최종 구간은 건드리지 않고 전략군을 다시 고른다.

**H-BUYBACK-01(보조)**: 자사주 취득 결정 다음 날 시가 매수, 4~10거래일 보유, 돌파 조건 없음. DS005 구조화 API로 취득 금액/시총 확보 후 사전 등록.

**데이터 보완**: 공식 휴장일 교차 확인(open.krx), 재무 위험 필터(감사의견·자본잠식 이력), 접수 시각.

## 9. 지켜야 할 규칙 (AGENTS.md 요약)

1. 수익성 확인 전 모든 수치는 가설. 종목 추천을 하지 않는다.
2. 당시 공개되지 않은 정보·정정 재무·미래 가격을 신호에 넣지 않는다.
3. 조건 변경은 새 버전과 실험 번호로. 실패도 `docs/runs/`에 기록. 시도 횟수 기록.
4. 최종 평가 구간을 반복 최적화에 쓰지 않는다. 검증·최종 구간은 사용자의 명시적 허락 후에만.
5. 가상 데이터·실데이터·모의·실거래를 구분해 표시한다.
6. 키·계좌 정보를 출력·커밋하지 않는다. 실제 주문 연동은 별도 범위.
