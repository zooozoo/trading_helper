# 진단 기록: 수주 공시 이벤트 스터디 DIAG-01 / DIAG-02 (2026-10-06)

데이터 종류: **실데이터**(OpenDART 신규 체결 공시 + 공공데이터포털 원주가). 결과 등급: **진단, 파라미터 탐색 없음**.
구간: development 2020-01-02 ~ 2024-01-31(반응일 기준). 재무 위험 필터 미적용. 비용 미반영(별도 추정).
명령: `python -m trading_helper diagnose-events --exp DIAG-02 --proxy mean`. 산출물 `outputs/experiments/DIAG-02/`.

## 정의
- D = 접수일(전부 거래일이었음), R = D 다음 첫 거래일, base = D 직전 거래일 종가.
- 반응 수익률 = base 종가 → R 종가. 접수일 수익률 = base → D 종가.
- 사후 수익률 = R 종가 → R+1/4/10/20 종가. 체결 가능 수익률 = R+1 시가 → R+5 시가(전략의 4거래일 보유).
- 시장 조정 = 보통주 전체의 **동일가중 평균** 일수익률 누적을 차감. 유동성 조건(직전 20일 평균 거래대금 10억 이상) 통과 4,403건.
- 플라시보 = 각 이벤트와 같은 반응일에 무작위로 뽑은 유동성 통과 보통주 1종목, 같은 지표.
- 버킷(사전 고정): 반응 수익률, 계약금액/시가총액, 사전 20일 수익률, 20일 시장 국면, R일 돌파 여부, 매출 대비 5%, 시장.

## DIAG-01의 오류와 수정
DIAG-01은 시장 대리변수로 일수익률 **중앙값**을 썼다. 중앙값은 일평균 −0.24%라 20일 누적 −4.5%가 되어
모든 종목이 +5% "초과수익"처럼 보였다. 플라시보(무작위 종목)도 +4.98%(t=20)가 나와 편향을 확인했다.
DIAG-02는 동일가중 **평균**(일평균 +0.03%)으로 교체하고 플라시보를 내장했다. 아래는 DIAG-02 기준.

## 결과 1: 정보는 접수일에 반영되고 그 뒤 드리프트는 없다

| 지표 (시장 조정) | 이벤트 n=4,403 | 플라시보 n=4,403 |
|---|---|---|
| 사전 20일 수익률 | +3.00% (중앙 +0.01%) | +2.05% |
| 접수일 수익률 | +0.88% (양의 비율 0.58, t=14) | - |
| 반응 수익률(base→R) | +0.96% (t=11) | −0.02% |
| R+1 시가 갭 | +0.24% | - |
| 사후 1일 | −0.08% | +0.01% |
| 사후 4일 | −0.03% (중앙 −0.97%) | −0.05% |
| 사후 10일 | +0.01% | −0.34% |
| 사후 20일 | +0.26% (t=1.0) | −0.66% |
| 체결 가능 R+1시가→R+5시가 | −0.08% (중앙 −1.02%) | −0.07% |

- 공시 효과는 약 +1%이며 **접수일 당일 종가에 이미 반영**된다. 반응일 R은 사실상 공시 다음 날이다.
- R 이후 1~20일 수익률은 이벤트와 플라시보가 구별되지 않는다. 4거래일 보유 전략이 가져갈 드리프트가 없다.
- 사전 20일 수익률이 플라시보보다 약 1%p 높다: 약한 사전 유출 또는 선반영 흔적.

## 결과 3: 돌파+거래량 그룹은 2020년 효과다

| 연도 | n | 평균 | 중앙값 | 양의 비율 |
|---|---|---|---|---|
| 2020 | 113 | +7.33% | +2.66% | 0.60 |
| 2021 | 67 | +2.92% | −0.18% | 0.49 |
| 2022 | 56 | −0.78% | −2.14% | 0.36 |
| 2023 | 65 | −1.00% | −2.57% | 0.37 |
| 2024(1월) | 5 | −6.43% | −6.43% | 0.20 |

- 상위 10% 거래가 총이익의 55%. 최대 +49.8%, 최소 −41.1%. 가정 비용 0.43% 차감 후 평균 +2.46%, 중앙값 −1.01%.
- 갭 >3%로 진입이 취소되는 25건은 평균 −2.54%였다: 상한 취소 규칙 자체는 해롭지 않다.
- 306건 중 금요일 반응은 72건뿐. 주간 모드(변형 A)는 이 중 금요일만 쓰므로 표본이 1/4로 준다.
- 코스닥 +6.37% vs 코스피 −0.92%, 계약/시총 <2% 그룹 +11.74%(n=88): **사후 분할 결과**이며 증거로 쓰지 않는다.
  검증하려면 새 실험 번호로 사전 등록해야 한다.

## 결론
1. 수주 공시의 가격 효과(약 +1%)는 접수일 당일에 끝난다. 다음 날 이후 보유로 얻을 드리프트는 없다.
2. "반응일 돌파" 조건은 집계상 양(+)이지만 2020년 코로나 반등 국면이 만든 것이고 2022년 이후는 음(−)이다.
   국면 의존적이며 소수 대형 수익에 집중된다. 견고한 우위로 볼 수 없다.
3. 주간 실행 모드는 반응일이 금요일인 이벤트만 쓰거나(표본 1/4) 금요일까지 기다려 판정하므로(신호 소멸),
   어느 쪽이든 일별 모드보다 나쁘다. **weekly_execution_v1 가설은 개발 구간에서 지지되지 않는다.**
4. 매출 대비 5% 문턱, 사전 수익률, 시장 국면 등 어떤 사전 고정 버킷도 안정적인 양의 사후 수익을 보이지 않았다.

## 한계
- 접수 시각 미확보: 장중/장후 공시 구분 불가. 장후 공시라면 R일이 진짜 반응일이고 분석이 달라질 수 있음.
- 재무 위험 필터 미적용. 비용은 추정치. 원주가(분할 후보 제외만 적용).
- 같은 날 여러 이벤트가 겹치므로 t값은 과대. 플라시보와의 차이를 우선 해석했다.
- 2024년은 1월 한 달(n=63)뿐.

## 다음 선택지 (각각 새 실험 번호, 사전 등록 후 개발 구간에서만)
- A. 이 전략군 중단. 수주 공시 돌파 매매는 2020년 이후 데이터에서 우위가 없다.
- B. 사전 등록 가설 1개만 검증: "코스닥 + 계약/시총 <2% + 반응일 돌파+거래량". 사후 분할에서 나온 것이므로
  개발 구간 재확인은 증거가 아니고, 검증 구간에서 한 번만 평가해야 한다. 표본 ~20건/년.
- C. 다른 이벤트 유형으로 전환(예: 자사주 취득, 무상증자, 실적 서프라이즈). 수집·정규화 파이프라인은 재사용 가능.
